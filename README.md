# The Integrity Compass

A 15-minute interactive presentation on academic integrity for graduate work in computing, built for the Luddy School of Informatics, Computing & Engineering.

**Live:** https://akesha.github.io/integrity/

## What it is

A single self-contained HTML file — 14 slides, no build step, no dependencies beyond Google Fonts. Runs from any browser or a local file.

The session walks through four decisions (code attribution, generative AI policy, research ethics, time management), two case studies (COMPAS, Amazon's resume screener), a silent self-check, and a two-minute resource scavenger hunt.

## Presenting it

| Key | Action |
| --- | --- |
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `N` | Toggle presenter notes |
| `T` | Pause/resume the session clock |
| `F` | Fullscreen |
| `R` | Reset the clock |
| `Home` / `End` | First / last slide |

Presenter notes carry the timing plan for each slide (0:00–15:00) plus what to say and what to expect from the room. The session clock starts automatically on the first advance.

Polls are counted live by clicking an option once per raised hand. The Reveal button stays locked until at least one vote is recorded.
